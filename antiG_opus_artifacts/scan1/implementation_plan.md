# 参数扫描与状态方程验证

## 目标

1. 扫描粒子直径 `d` 和 Lennard-Jones 势阱深度 `l_j_epsilon`
2. 每个参数点运行到平衡态
3. 测量平衡压力，验证状态方程（EOS）
4. 与成熟的 MD / DSMC 方法的理论结果进行比较

## 物理背景

该模拟是一个基于网格的随机碰撞模拟，结合了：
- **硬球碰撞**：粒子直径 `d` 决定碰撞截面
- **Lennard-Jones 力**：`l_j_epsilon` 控制粒子间引力/斥力强度

状态方程关系：**P = f(ρ, T, d, ε)** 其中 ρ = N/V 为数密度。

### 理论参考

| 极限情况 | 理论 EOS | 说明 |
|---------|---------|------|
| 理想气体 (d→0, ε→0) | PV = NkT | 无相互作用 |
| 硬球气体 (ε=0) | P/(ρkT) = 1 + B₂ρ + ... | Carnahan-Starling EOS |
| LJ 流体 | Johnson-Zollweg-Gubbins (JZG) | 经典 MD 参考 |

**Carnahan-Starling** 硬球 EOS:
```
Z = PV/(NkT) = (1 + η + η² - η³) / (1 - η)³
η = πρd³/6  (packing fraction)
```

## 参数空间

### 固定参数
- `N = 16384`, `L = 8` → ρ = N/L³ = 32 (无量纲数密度)
- `mass = 200.0`, `n_test = 1`
- `temperature = 1.0` → `e0 = 1.5`
- `bounded = true`（有界容器才能测量压力）

### 扫描参数

#### Scan 1: 扫描 d（纯硬球，ε=0）
验证 Carnahan-Starling EOS

| d | η = πρd³/6 | dt | 预期 Z |
|---|-----------|-----|--------|
| 0.05 | 0.0021 | 4.0 | ≈1.008 |
| 0.10 | 0.0168 | 1.0 | ≈1.07 |
| 0.15 | 0.0565 | 0.44 | ≈1.25 |
| 0.20 | 0.134 | 0.25 | ≈1.65 |
| 0.25 | 0.262 | 0.16 | ≈2.58 |
| 0.30 | 0.452 | 0.11 | ≈5.22 |

> [!NOTE]
> `dt` 按 `0.01 / d²` 缩放，确保碰撞概率 < 1。
> 对于 ε=0 的情况，需要在 config 中设 `l_j_epsilon = 0`。

#### Scan 2: 扫描 l_j_epsilon（固定 d=0.2）
验证 LJ 力的影响

| l_j_epsilon | 说明 | 预期效果 |
|-------------|------|---------|
| 0.0 | 纯硬球 | 基线 Z |
| 0.01 | 弱引力 | Z 略降 |
| 0.1 | 中等引力 | Z 显著降低 |
| 1.0 | 强引力 | 可能相变 |
| 10.0 | 极强引力 | 凝聚态 |

### 平衡判定

- **方法**：监测后 50% 步数的压力滚动平均值的标准差
- **步数**：先跑 2000 步探测平衡时间，然后取后 1000 步平均
- **总步数**：每个配置跑 **3000 步**（前 2000 步弛豫，后 1000 步采样）

> [!IMPORTANT]
> 低温或高密度情况可能需要更多步数达到平衡。我们先跑 3000 步，如果压力未收敛再增加。
